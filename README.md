# Мониторинг санкционных новостей

Telegram-бот для мониторинга санкций, экспортного контроля и торговых ограничений, связанных с Россией.
Собирает публикации из официальных источников и извлекает сведения из RSS, веб-страниц и документов.
Языковая модель отбирает релевантные события и готовит краткие описания на русском языке.
Ежедневная сводка приходит в Telegram со ссылками на первоисточники.

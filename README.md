# Telegram-бот для мониторинга санкционных и торговых новостей

Проект представляет собой систему автоматического мониторинга новостей о **санкциях, экспортном контроле и международной торговле**.
Бот собирает публикации с официальных сайтов регуляторов, анализирует их с помощью LLM и отправляет **ежедневную сводку в Telegram**.

Основная цель — упростить отслеживание изменений в санкционном регулировании и экспортных ограничениях для специалистов, работающих с международными поставками.

---

## Основные возможности

* автоматический сбор новостей из нескольких источников
* поддержка разных способов извлечения данных (RSS, HTML-парсинг, Selenium)
* фильтрация релевантных новостей с помощью LLM
* формирование краткой новостной сводки
* отправка результатов через Telegram-бота

---

## Архитектура системы

```
Источники новостей
        ↓
Сбор данных (RSS / парсинг сайтов)
        ↓
Анализ новостей (Perplexity API)
        ↓
Формирование сводки
        ↓
Telegram-бот
```

1. **Сбор данных**
   Скрипт проходит по списку источников и извлекает новые публикации.
   Используются RSS-ленты, HTML-парсинг и Selenium для динамических страниц.

2. **Анализ новостей**
   После сбора данные передаются в модель через API.
   Модель определяет релевантность новости и формирует краткое описание.

3. **Отправка сводки**
   Telegram-бот отправляет итоговую подборку пользователям.
